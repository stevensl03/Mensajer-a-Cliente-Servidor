# Mensajer-a-Cliente-Servidor
Servidor de mensajería académica cliente/servidor en Java 21 sobre TCP/IP, por capas y componentes con Maven. Autentica usuarios, procesa texto (SHA-256, palabras/caracteres) e imágenes con 5 filtros, y los guarda en colas en memoria, MySQL y disco. Vistas de consola y escritorio, fachada, logging, inyección de dependencias y fábricas de objetos.
